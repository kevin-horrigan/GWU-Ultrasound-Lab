# Dr. Vesna Zderic Ultrasound Laboratory — Equipment Manual & Training Guide

George Washington University, School of Engineering and Applied Science

A version-controlled knowledge base for the lab: one page per instrument, a from-scratch
ultrasound-engineering course taught on that same equipment, and the lab's chemical safety record.

Most ultrasound teaching material is written against a textbook. This is written against a specific
bench, by someone who arrived without a hardware background and had to learn to use every instrument
in it. If you run a university ultrasound lab, or you are a student about to be handed a hydrophone
and a function generator for the first time, that is who this is for.

## Layout

| Folder | What is in it |
|---|---|
| `Equipment/` | One page per instrument in `items/`, numbered in official-inventory order. `Equipment/README.md` is the grouped index and `INVENTORY.md` is the full list. |
| `Learning/` | Ultrasound-engineering course, one module at a time, taught on the lab's own instruments. |
| `Safety/` | Chemical inventory and safety data sheets. |

## Manufacturer manuals

Instrument manuals are **not redistributed here**. Each equipment page names the model so you can get
the current manual from the manufacturer, which is also the version you want rather than whichever one
we happened to download.

## Scope

This repository covers instruments, instruction and safety. Active research projects, build plans and
experimental records are kept separately and are not part of this publication.

## Contributions

Corrections are welcome, particularly from anyone who has used the same instruments and found our notes

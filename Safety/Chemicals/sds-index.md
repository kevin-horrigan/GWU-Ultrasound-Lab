# SDS index

Generated by `../tools/sds_lookup.py`. Two columns that can be automated, and one that cannot.

**GHS** comes from PubChem PUG-REST by CAS. It is the substance-level regulatory picture and it
is good for sorting a shelf or spotting an acute toxin. **It is not an SDS.** The Chemical Hygiene
Plan wants the manufacturer's own current sheet for the container you are holding, so the last
column is a search link and someone still has to download the PDF and check the catalogue number
matches the bottle.

Mixtures (media, buffers, stains) have no single CAS and show no GHS here. Use the supplier link.
